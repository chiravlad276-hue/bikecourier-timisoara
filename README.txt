BIKECOURIER TIMISOARA — PWA

Fișiere necesare: index.html, manifest.webmanifest, sw.js, icon.svg.

PUBLICARE
În repository-ul GitHub creat, apasă Add file > Upload files, selectează cele patru fișiere, apoi Commit changes.
Apoi Settings > Pages > Deploy from a branch > Branch: main > Folder: / (root) > Save.
Așteaptă publicarea și deschide adresa https://NUME-UTILIZATOR.github.io/bikecourier-timisoara/ în Safari.
În Safari: Share > Add to Home Screen > Add.

Datele sunt păstrate local pe dispozitiv/browser. Exportă periodic CSV. Aplicația nu se conectează la Bolt și nu importă automat comenzi sau vreme. Netul este o estimare pe baza comisionului de 10% și a taxei săptămânale estimate din interfață; verifică tarifele reale ale flotei.
